Resposta:
Com base na base de conhecimento, o artigo relevante para o chamado P12 é:

**Artigo 2: Impressora de rede - troubleshooting**

Procedimento descrito no artigo para solucionar problemas de impressora de rede:

1. Verifique se a impressora esta ligada e conectada; LED de rede aceso.
2. Execute ping para o IP da impressora.
3. Acesse a interface web da impressora para checar suprimentos e rede.
4. Remova e reinstale a impressora no computador do usuario.
5. Verifique a fila no servidor de impressao.
6. Reinicie o servico Spooler de Impressao.

Causas comuns: cabo desconectado, IP conflitante, driver corrompido.
