Caso P10 - execucao 1
Consulta: preciso colocar um programa novo no meu computador, ele é liberado?
Esperado: Instalacao de software homologado

Artigos recuperados (ordem):
- Instalacao de software homologado
- Atualizacao do Windows travada
- Driver de impressora - instalacao e atualizacao

Resposta:
Com base na base de conhecimento do GLPI, identifiquei o artigo relevante para o seu chamado:

**Artigo: Instalação de software homologado**

Procedimento de instalação de software padrão:

1. Confirme que o software está na lista de homologados.
2. Baixe o instalador do repositório interno.
3. Execute a instalação com privilégios administrativos.
4. Registre a licença e o número do chamado.

> Observação: os demais artigos da base (Atualização do Windows travada e Driver de impressora – instalação e atualização) não são aplicáveis ao seu caso, pois tratam de outros tipos de problema.
