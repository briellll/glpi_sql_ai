Caso P10 - execucao 3
Consulta: preciso colocar um programa novo no meu computador, ele é liberado?
Esperado: Instalacao de software homologado

Artigos recuperados (ordem):
- Instalacao de software homologado
- Atualizacao do Windows travada
- Driver de impressora - instalacao e atualizacao

Resposta:
Com base no artigo **“Instalacao de software homologado”**, para verificar se o programa novo é liberado, siga o procedimento descrito:

**Instalacao de software padrao:**
1. Confirme que o software esta na lista de homologados.
2. Baixe o instalador do repositorio interno.
3. Execute a instalacao com privilegios administrativos.
4. Registre a licenca e o numero do chamado.
